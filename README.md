# MaSTRspy

**Smart STR Analysis Pipeline** — A PySide6-based bioinformatics application for automated Short Tandem Repeat (STR) analysis of nanopore and long-read sequencing data.

MaSTRspy detects input file types automatically and builds an adaptive workflow that guides users from raw sequencing data through basecalling, alignment, quality filtering, and STR profiling — producing per-sample allele calls, zygosity determinations, and publication-ready visualizations.

## Features

- **Automatic file detection** — POD5, BAM (aligned/unaligned), and FASTQ inputs are classified on the fly; unnecessary pipeline stages are skipped
- **Adaptive workflow** — POD5 runs all four stages; aligned BAMs skip straight to analysis
- **Quality filtering** — Configurable presets (Lenient, Moderate, Stringent) or custom thresholds for Dorado QS, mean Phred quality, read length, and alignment accuracy
- **45-locus STR database** — Autosomal and Y-STR markers mapped to GRCh38
- **Normalization and stutter detection** — Multiple normalization methods with configurable per-locus cutoff overrides
- **Multi-sample processing** — Barcode-aware demultiplexing and per-barcode result organization
- **Checkpoint/resume** — Long-running analyses can resume from the last completed locus
- **Interactive GUI** — Step-by-step wizard with real-time log monitoring and progress tracking
- **Structured logging** — Timestamped log files with run parameters, stage separators, and elapsed-time summaries
- **Docker support** — Multi-stage Dockerfile with X11 forwarding for containerized GUI runs

## Requirements

### Python

- Python >= 3.9

### External tools

| Tool | Purpose | Required |
|------|---------|----------|
| [samtools](https://www.htslib.org/) | SAM/BAM manipulation | Yes |
| [bedtools](https://bedtools.readthedocs.io/) | Genomic interval operations | Yes |
| [minimap2](https://github.com/lh3/minimap2) | Long-read alignment | Yes |
| [xatlas](https://github.com/broadinstitute/xatlas) | SNV calling within STR regions | Optional |
| [dorado](https://github.com/nanoporetech/dorado) | ONT basecalling (POD5 input) | Optional |
| [Rscript](https://www.r-project.org/) | ggplot2-based profile plots | Optional |

```
PySide6 >= 6.5

```

## Installation

### From source

```bash
git clone https://github.com/DP-Genome/MaSTRspy.git
cd MaSTRspy
pip install .
```

For development:

```bash
pip install ".[dev]"
```

### Docker

```bash
docker build -t mastrspy .
```

Run with X11 forwarding (Linux):

```bash
xhost +local:docker
docker run -e DISPLAY=$DISPLAY -v /tmp/.X11-unix:/tmp/.X11-unix mastrspy
```

Mount a data directory:

```bash
docker run -e DISPLAY=$DISPLAY \
  -v /tmp/.X11-unix:/tmp/.X11-unix \
  -v /path/to/data:/data \
  mastrspy
```

## Usage

### Launch the GUI

```bash
MaSTRspy activate
```

Or run directly without installing:

```bash
python main.py activate
```

The wizard walks through these pages:

1. **Welcome** — Overview and dark-mode toggle
2. **File Selection** — Browse to an input directory; file type is auto-detected
3. **Experiment Setup** — Name the run and choose an output directory
4. **Basecalling** *(POD5 only)* — Select a Dorado model and demultiplexing kit
5. **Filtering** — Pick a quality-filter preset or set custom thresholds
6. **Analysis Options** — Reference genome, normalization cutoff, per-locus overrides, thread control, optional SNV calling
7. **Review** — Confirm all settings before starting
8. **Processing** — Live log output and stage progress indicators
9. **Results** — Browse summary tables, STR profiles, and allele plots

### Pipeline stages

| Stage | Input | Output | Tools |
|-------|-------|--------|-------|
| Basecalling | POD5 | `1_basecalled.bam` | dorado |
| Demultiplexing | BAM | `2_demuxed/` | dorado demux |
| Prepping | BAM / FASTQ | `3_prepped/` | minimap2, samtools |
| Analysis | Aligned BAM | `4_analysis/` | bedtools, samtools, xatlas (optional) |

The prepping stage applies filters in sequence:

- **FASTQ quality** — minimum mean Phred score and read length
- **Dorado QS** — minimum quality score from the `qs` BAM tag
- **BAM accuracy** — alignment accuracy derived from MD tag and CIGAR

### Output structure

```
<output_dir>/<experiment_name>/
  <experiment_name>_YYYYMMDD_HHMMSS.log
  1_basecalled.bam          (POD5 only)
  2_demuxed/                (POD5 only)
  3_prepped/                (if prepping was needed)
  4_analysis/
    IntersectMappedReads/
    Countings/
    Summaries/
      barcode01_summary.tsv
      barcode01_Profile.tsv
    Plots/
      barcode01_profile.png
    Combined_Report.tsv
```

## Configuration

### `config/ToolsConfig.txt`

Paths to external tools:

```
BEDTOOLS=/usr/bin/bedtools
MINIMAP=/usr/bin/minimap2
SAMTOOLS=/usr/bin/samtools
XATLAS=/usr/local/bin/xatlas
```

### `config/InputConfig.txt`

Runtime parameters (auto-generated by the GUI):

```
INPUT_DIR=/path/to/input
OUTPUT_DIR=/path/to/output
INPUT_BAM=yes
READ_TYPE=ont
GENOME_FASTA=/path/to/reference.fa
REGION_BED=/path/to/DBv5.bed
NORM_CUTOFF=0.1
NUM_PARALLEL_JOBS=2
NUM_THREADS=4
ENABLE_SNV=no
```

The GUI exposes a single **Total Threads** control. The system auto-splits it into parallel jobs and threads per job:

- **>= 64 threads:** 8 parallel jobs
- **< 64 threads:** 2 parallel jobs

**SNV calling (xatlas)** is disabled by default. When enabled, xatlas failures are non-fatal — the pipeline logs a warning and continues STR genotyping for every locus regardless.

### Filter presets

| Preset | Dorado QS | Mean Q | Min Length | Accuracy |
|--------|-----------|--------|------------|----------|
| Lenient | 7 | 7 | 100 | 0.80 |
| Moderate | 10 | 10 | 200 | 0.85 |
| Stringent | 14 | 14 | 300 | 0.90 |

## MaSTR Database

The `MaSTRDB/` directory contains reference data for 47 STR loci:

- `DBv5.bed` — Genomic coordinates (GRCh38) for all loci
- `Database/{LOCUS}.fa` — Per-locus FASTA reference sequences
- `Database/{LOCUS}.bed` — Per-locus BED regions
- `Database/{LOCUS}.fai` — Samtools FASTA indices

Loci include autosomal markers (CSF1PO, D-series, FGA, PentaD/E, TH01, TPOX, vWA) and Y-STR markers (DYS-series, YGATAH4).
